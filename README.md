One last text message a phone sends at one percent battery, in the voice of the dying phone itself.

> This is my last text. The charger is three feet away and you are still scrolling. Goodbye, and charge me next time.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the entry line from `entry.txt` and writes it to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (falling back to `MAKEFUN_BOT_DIR`, then a local `output` folder).

```sh
node main.ts
```
